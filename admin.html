First-time setup

No admin password is set yet. Enter a GitHub fine-grained personal access token with Contents: read and write on the releases repository, and choose a password. The token is encrypted with the password (PBKDF2 + AES-GCM) and stored in the repository as admin.enc; only the password unlocks it.

Forgot it? Delete admin.enc in the repository to run setup again.
